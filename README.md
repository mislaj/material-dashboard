# 📊 Modern Admin Dashboard (React.js)

This is a pixel-perfect, responsive, and performance-optimized **Admin Dashboard UI** built using **React.js**, **raw CSS**, and **Chart.js**. It replicates a professional analytics design, including a sidebar, KPI cards, interactive charts, and country-wise statistics.

---

## 🚀 Features

- ⚙️ React functional components with modular structure
- 🎨 Fully custom-styled using **raw CSS** (no UI libraries)
- 📈 Integrated **Chart.js** for dynamic charts (line, pie, bar)
- 📱 Fully responsive layout (desktop/tablet/mobile)
- 🧭 Expandable & collapsible sidebar with icons and active states
- 🌍 Country stats with flag icons and change indicators
- 🔍 Code-splitting and component reusability for performance
